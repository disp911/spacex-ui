# Фронтенд панели

Vue 3 + Vite + TypeScript. Сборка попадает в `web/dist` и вшивается в бинарник
через `go:embed`, так что Node.js нужен только для разработки и в CI.

Сейчас на новом фронте работают вход и дашборд (со всеми модалками); остальные
страницы пока отдаются старыми шаблонами из `web/html`. Пока `web/dist` не собран,
панель показывает старые страницы и для входа с дашбордом.

## Разработка

```bash
cd frontend
npm ci
npm run dev          # пересобирает web/dist при каждом изменении
```

В соседнем терминале запустите панель так, чтобы она читала `web/dist` с диска:

```bash
XUI_DEBUG=true go run ./main.go
```

## Проверка и сборка

```bash
npm run typecheck    # проверка типов
npm run build        # production-сборка в web/dist
```

## Устройство

- `src/styles/tokens.css` — цвета тёмной и светлой темы (по макетам из `web/new-design`)
- `src/lib/` — API, переводы, тема, WebSocket, форматирование
- `src/components/` — общие компоненты: модалка, выпадающий список, подтверждение, карточки
- `src/pages/` — страницы, `src/modals/` — модалки дашборда

Переводы берутся из `web/translation/*.toml`: сервер встраивает их в страницу.
Новые строки интерфейса лежат в секции `[spx]`.
